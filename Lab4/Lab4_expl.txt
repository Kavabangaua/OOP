Звіт з виконання лабораторної роботи №4 
(Клонування екземплярів класу з використанням метакласів та декораторів)

1. Аналіз

1.1 Що треба зробити:
- Забезпечити можливість клонування екземплярів класу
- Реалізувати метаклас або декоратор, який автоматично додає метод клонування
- Клонування повинно створювати копію даних екземпляра (без методів)
- Додати можливість відновлення початкового стану клону

2. Реалізація метакласу (CloneableMeta)

2.1 Принцип роботи:
- Метаклас перехоплює процес створення класу
- Під час створення класу додає метод clone()
- Метод clone() створює глибоку копію екземпляра
- В копію додається метод restore() для відновлення стану

2.2 Деталі реалізації:
- Використовується метод __new__ метакласу для модифікації класу
- При клонуванні створюється знімок (snapshot) всіх даних екземпляра
- Знімок даних зберігається в замиканні функції restore
- Метод restore додається до клону як лямбда-функція
- Використовується copy.deepcopy() для створення глибоких копій

3. Реалізація декоратора (cloneable)

3.1 Принцип роботи:
- Декоратор модифікує клас, додаючи необхідні методи
- Перевизначає конструктор __init__ для збереження початкового стану
- Додає метод clone() для створення копії
- Додає метод restore() для відновлення стану клону

3.2 Деталі реалізації:
- Зберігається оригінальний конструктор класу
- Створюється новий конструктор, який викликає оригінальний і зберігає стан
- Метод clone() створює копію об'єкта і зберігає його поточний стан
- Метод restore() відновлює збережений стан
- Використовується wraps для збереження метаданих оригінального конструктора

4. Демонстраційні класи

4.1 Клас Person (з метакласом):
- Демонструє використання метакласу

5. Порівняння підходів

5.1 Переваги метакласу:
- Більш "прозорий" для користувача класу
- Не потребує явної декорації класу
- Автоматично застосовується до всіх підкласів

5.2 Переваги декоратора:
- Легше у використанні та розумінні
- Більш явний синтаксис
- Більш гнучкий у налаштуванні

5.3 Спільні моменти:
- Обидва підходи додають методи clone() та restore()
- Обидва використовують глибоке копіювання для створення клонів
- Обидва забезпечують відновлення початкового стану

6. Технічні особливості

6.1 Глибоке копіювання:
- Використання copy.deepcopy() для створення повних копій об'єктів
- Забезпечує незалежність оригіналу та клону
- Копіює всі вкладені структури даних

6.2 Замикання:
- Використання замикань для збереження стану
- Дозволяє методу restore мати доступ до збереженого стану
- Забезпечує інкапсуляцію даних для відновлення

6.3 Динамічне додавання методів:
- Додавання методів до класу під час його створення/модифікації
- Додавання методів до екземпляра під час клонування
- Використання функцій-фабрик для створення методів

8. Детальний опис коду (для захисту)

8.1 Імпорт необхідних модулів:

```python
import copy                # Рядок 1: Імпортуємо модуль copy для створення копій об'єктів
from functools import wraps # Рядок 2: Імпортуємо wraps для збереження метаданих функцій
```

Модуль copy надає функції для створення копій об'єктів. 
Особливо важлива функція deepcopy, яка створює повну копію об'єкта, 
включаючи всі вкладені об'єкти. Декоратор wraps потрібен для збереження 
інформації про оригінальну функцію (імені, документації тощо) при її обгортанні іншою функцією.

8.2 Реалізація метакласу:

```python
class CloneableMeta(type):           # Рядок 5: Створюємо метаклас, який наслідує type
    def __new__(mcs, name, bases, attrs): # Рядок 6: Перевизначаємо метод __new__
```

Метакласи в Python — це класи, що створюють інші класи. Базовим метакласом є type.
 Метод __new__ перевизначається для модифікації класу під час його створення. 
Параметри:
- mcs — сам метаклас
- name — ім'я класу, що створюється
- bases — батьківські класи
- attrs — атрибути класу

```python
        def clone(self):                 # Рядок 8: Визначаємо метод clone
            data_snapshot = {key: value for key, value in self.__dict__.items()} # Рядок 10: Створюємо словник атрибутів
```

Тут ми визначаємо метод clone, який буде додано до класу. Використовуємо генератор 
словника для створення копії всіх атрибутів екземпляра.

```python
            def restore(self_instance):    # Рядок 13: Визначаємо функцію відновлення
                for key, value in data_snapshot.items(): # Рядок 14: Обходимо всі атрибути
                    setattr(self_instance, key, copy.deepcopy(value)) # Рядок 15: Встановлюємо атрибути
                return self_instance      # Рядок 16: Повертаємо оновлений екземпляр
```

Функція restore відновлює стан екземпляра з попередньо збереженого знімка. 
Вона приймає екземпляр та змінює його атрибути на ті, що збережені в data_snapshot. 
Використовуємо deepcopy для запобігання проблем з мутабельними типами.

```python
            new_instance = copy.deepcopy(self) # Рядок 19: Створюємо глибоку копію екземпляра
            new_instance.restore = lambda: restore(new_instance) # Рядок 20: Додаємо метод restore
            return new_instance            # Рядок 21: Повертаємо клон
```

Створюємо глибоку копію оригінального об'єкта і додаємо до неї метод restore як лямбда-функцію. 
Лямбда-функція викликає раніше визначену функцію restore, передаючи їй копію як аргумент. 
Це забезпечує замикання над змінною data_snapshot.

```python
        attrs['clone'] = clone              # Рядок 23: Додаємо метод clone до атрибутів класу
        return super().__new__(mcs, name, bases, attrs) # Рядок 24: Викликаємо батьківський метод
```

Додаємо визначений раніше метод clone до атрибутів класу і викликаємо метод
 __new__ базового класу type для створення класу.

8.3 Реалізація декоратора:

```python
def cloneable(cls):                  # Рядок 28: Визначаємо декоратор
    original_init = cls.__init__       # Рядок 29: Зберігаємо оригінальний конструктор
```

Декоратор — це функція, яка приймає клас і повертає модифікований клас.
Ми зберігаємо посилання на оригінальний конструктор класу.

```python
    @wraps(original_init)              # Рядок 31: Зберігаємо метадані оригінального конструктора
    def __init__(self, *args, **kwargs): # Рядок 32: Створюємо новий конструктор
        original_init(self, *args, **kwargs) # Рядок 33: Викликаємо оригінальний конструктор
        self.__initial_state = copy.deepcopy(self.__dict__) # Рядок 35: Зберігаємо початковий стан
```

Створюємо новий конструктор, який викликає оригінальний і зберігає копію
початкового стану об'єкта. Декоратор @wraps зберігає метадані оригінального 
конструктора (ім'я, документацію тощо).

```python
    def clone(self):                   # Рядок 37: Визначаємо метод clone
        new_instance = copy.deepcopy(self) # Рядок 39: Створюємо копію об'єкта
        new_instance.__clone_state = copy.deepcopy(new_instance.__dict__) # Рядок 41: Зберігаємо стан
```

Визначаємо метод clone, який створює глибоку копію об'єкта і зберігає
поточний стан для можливості відновлення.

```python
        def restore():                  # Рядок 43: Визначаємо функцію відновлення
            for key, value in new_instance.__clone_state.items(): # Рядок 45: Обходимо атрибути
                if key != "__clone_state": # Рядок 46: Перевіряємо, чи це не атрибут стану
                    setattr(new_instance, key, copy.deepcopy(value)) # Рядок 47: Встановлюємо атрибут
            return new_instance        # Рядок 48: Повертаємо оновлений екземпляр
```

Визначаємо функцію restore, яка відновлює стан об'єкта з збереженого знімка. 
Перевірка на "__clone_state" потрібна для запобігання рекурсії.

```python
        new_instance.restore = restore   # Рядок 51: Додаємо метод restore
        return new_instance            # Рядок 52: Повертаємо клон
```

Додаємо метод restore до клону і повертаємо його.

```python
    cls.__init__ = __init__              # Рядок 55: Замінюємо конструктор
    cls.clone = clone                  # Рядок 56: Додаємо метод clone
    return cls                         # Рядок 57: Повертаємо модифікований клас
```

Замінюємо конструктор класу і додаємо метод clone. Повертаємо модифікований клас.

8.4 Демонстраційні класи та їх використання:

У коді реалізовано два демонстраційні класи: Person (використовує метаклас) і 
Student (використовує декоратор). Обидва класи мають схожу структуру з деякими 
атрибутами та методами.

```python
class Person(metaclass=CloneableMeta):  # Рядок 60: Визначаємо клас з метакласом
```

Клас Person використовує CloneableMeta як метаклас. Це означає, що клас Person
буде створено за допомогою CloneableMeta.__new__.

```python
@cloneable                           # Рядок 75: Застосовуємо декоратор до класу
class Student:                       # Рядок 76: Визначаємо клас
```

Клас Student декорується функцією cloneable. Це означає, що cloneable(Student) 
виконується під час визначення класу.

У функції main демонструється використання обох класів. Створюються екземпляри, 
клонуються, модифікуються і відновлюються. Це показує, що:
1. Клони незалежні від оригіналів
2. Клони можуть змінюватись незалежно
3. Клони можуть бути відновлені до стану на момент клонування

8.5 Висновки щодо реалізації:

Обидва підходи (метаклас і декоратор) забезпечують ту саму функціональність —
можливість клонування об'єктів і відновлення їх стану. Вибір між ними залежить 
від конкретного використання:

- Метаклас добре підходить, коли потрібно додати функціональність до всієї 
ієрархії класів без явного зазначення
- Декоратор більш явний і легше використовується, коли потрібно вибірково додати 
функціональність

Обидва підходи демонструють потужність Python у динамічному створенні та
модифікації класів під час виконання програми. \n

9.2 Поняття метапрограмування.
    - Загалом: Метапрограмування – це техніка написання коду, який маніпулює іншим кодом (
        або самим собою) як даними. Тобто, це програми, що пишуть або модифікують інші програми 
        (або їх частини) під час компіляції або виконання. В Python це може включати динамічне 
        створення або зміну класів, функцій, додавання атрибутів "на льоту", використання декораторів
        та метакласів. Це дозволяє створювати більш гнучкий, адаптивний та менш багатослівний код.

9.3 Як задається метаклас для класу.
    - Згідно з файлом Lab4/Lab4_expl.txt (розділ 8.4):
        - Клас Person використовує метаклас CloneableMeta: `class Person(metaclass=CloneableMeta):`
        - "Це означає, що клас Person буде створено за допомогою CloneableMeta.__new__."
    - Загалом: В Python 3 метаклас для класу задається за допомогою аргументу `metaclass` 
    у визначенні класу:
      ```python

          pass # Логіка метакласу

      class MyClass(metaclass=MyMeta):

      ```
      Якщо `metaclass` не вказано явно, Python використовує метаклас `type` за замовчуванням. 
      Метаклас також може бути успадкований від батьківського класу.

9.4 Методи контролю доступу до атрибутів класу, особливості їх реалізації та застосування.
    - Загалом, у Python існують такі основні підходи:
        - Угоди про іменування:
            - `_одинарне_підкреслення`: Атрибут призначений для внутрішнього використання 
            (це лише угода, доступ не обмежується).
            - `__подвійне_підкреслення`: "Спотворення імен" (name mangling). 
            Python перейменовує такі атрибути, щоб уникнути конфліктів імен у підкласах 
            (наприклад, __attr в класі MyClass стане _MyClass__attr).
        - Властивості (Properties): 
        Використання декоратора `@property` та відповідних сеттерів (`@name.setter`) і 
        делітерів (`@name.deleter`) дозволяє визначати методи, які поводяться як атрибути. 
        Це дає можливість додати логіку при отриманні, встановленні або видаленні значення атрибута.
          ```python
          class MyClass:
              def __init__(self):
                  self._value = None

              @property
              def value(self):
                  print("Getting value")
                  return self._value

              @value.setter
              def value(self, new_value):
                  print(f"Setting value to {new_value}")
                  if new_value < 0:
                      raise ValueError("Value cannot be negative")
                  self._value = new_value
          ```
        - Спеціальні методи `__getattr__`, `__setattr__`, `__delattr__`, `__getattribute__`:
            - `__getattr__(self, name)`: Викликається, якщо атрибут `name` не знайдено звичайним шляхом.
            - `__setattr__(self, name, value)`: Викликається при кожній спробі присвоїти значення атрибуту `name`.
            - `__delattr__(self, name)`: Викликається при видаленні атрибута `name`.
            - `__getattribute__(self, name)`: Викликається при кожній спробі доступу до атрибута `name`.
    - Застосування: Ці методи використовуються для інкапсуляції, валідації даних, створення 
    "обчислених" атрибутів, логування доступу, реалізації проксі-об'єктів тощо.

9.5 Додавання методів та властивостей класу у процесі роботи програми.
        - Метаклас `CloneableMeta` "під час створення класу додає метод `clone()`".
        - Також він додає метод `restore` до екземпляра клону.
        - Декоратор `cloneable` "модифікує клас, додаючи необхідні методи". 
        Він також додає метод `restore` до екземпляра* клону.
    - Загалом, методи та властивості можна додавати динамічно:
        - Додавання до класу:
          ```python
          class MyClass:
              pass

          def new_method(self):
              print("Hello from new_method")

          MyClass.new_method_on_class = new_method
          ```
          Властивості (`property`) також можна додати до класу після його визначення, використовуючи функцію `property()`:
          ```python
          class MyClass:
              def __init__(self):
                  self._x = 0
              def get_x(self): return self._x
              def set_x(self, val): self._x = val

          MyClass.x = property(MyClass.get_x, MyClass.set_x)
          ```
        - Додавання до екземпляра:
          ```python
          import types

          class MyClass:
              pass

          obj = MyClass()

          def instance_method(self): # self тут буде посилатися на obj
              print(f"Method on instance {id(self)}")

          obj.my_method = types.MethodType(instance_method, obj)
          obj.my_method()
          ```

9.6 Створення нових класів під час роботи програми.
    - Загалом, нові класи можна створювати динамічно за допомогою:
        - Функції `type()`:
          ```python
          # type(name, bases, dict)
          MyDynamicClass = type(\'MyDynamicClass\', (object,), {\'my_attr\': 100})
          dyn_obj = MyDynamicClass()
          print(dyn_obj.my_attr)
          ```
        - Метакласів: Можна написати метаклас, який генерує нові класи на основі певних 
        параметрів або умов під час виконання програми.
